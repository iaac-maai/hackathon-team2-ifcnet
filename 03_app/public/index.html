    How it works

    From a file to a verdict in four steps

    1. Step 1

      Read the IFC

      The model server opens your element and takes 256 points from its surface, scaled to fit a unit sphere.

    2. Step 2

      Build a graph

      Each point is linked to its nearest neighbours (a k-nearest-neighbour graph), so the network sees the shape, not the name.

    3. Step 3

      32 numbers, then rebuild

      The graph autoencoder compresses the shape into 32 numbers and rebuilds 256 points from them.

    4. Step 4

      Compare

      The score is the Chamfer distance between the two point sets. Above the threshold, the element is unusual.
