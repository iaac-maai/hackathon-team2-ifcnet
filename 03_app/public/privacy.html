Privacy

What this research prototype stores, what it does not, and who can see it.

What we store

Each analysis adds one row to a Cloudflare D1 database (table predictions). A row holds:

  • a random id
  • the date and time (UTC)
  • the file name
  • the anomaly score
  • the threshold
  • the verdict (normal / unusual)

Nothing else.

What we do not store

  • The uploaded IFC file itself (there is no file storage; R2 is not used).
  • Its geometry or its embedding.
  • Names of people, e-mail addresses or accounts. There are no user accounts.

The model server (Render)

Your file is sent once to our model server. It is written to a temporary file for the analysis and deleted right after.

The server keeps the computed result in memory for a short time, so it can answer repeated requests faster. This memory is cleared when the server restarts, or when it goes to sleep after 15 minutes without use.

The server is not password protected, but it stores nothing on disk.

Who can see results

Everyone who knows the team password sees the "Saved results" list, including file names.

Do not upload files whose names or contents are confidential.

Usage statistics

We use Cloudflare Web Analytics to count visits: page views, country, browser and device type, and page load time. It uses no cookies and does not identify you. We only see totals. It does not see your files or results.

Cookies

One login cookie, which holds a hash of the team password, not the password. No tracking cookies.

Third parties

  • Fonts are loaded from Google Fonts and the 3D library (three.js) from the jsDelivr CDN, so these services see your IP address when the page loads.
  • Cloudflare and Render, which host the app, may keep standard technical request logs.
  • The model files on Hugging Face contain no user data.

How long

Saved results stay until the end of the course (November 2026 hackathon, IAAC MaAI). Then the database is deleted.

Want a row removed earlier? Ask IAAC MaAI Team 2 through the course.

Who

IAAC MaAI 2026/27, AI Methods I hackathon, Team 2: Bars Babila, Samiha Abeda Nur, Emmanuel Marquez, Karthikeyan Saravanan.

This is a research prototype for coursework, not a commercial service.
